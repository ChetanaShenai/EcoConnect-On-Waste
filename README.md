## 📌 Overview

EcoConnect-On-Waste is a web-based waste management platform designed to connect citizens, NGOs, and recyclers to encourage responsible waste disposal and recycling.

The platform helps users schedule waste pickups, connect with nearby NGOs, and promote environmental sustainability through a simple and user-friendly interface.

---

## ✨ Features

- ♻️ Waste collection scheduling
- 🏢 NGO registration and management
- 👤 User authentication
- 📍 Waste disposal awareness
- 📱 Responsive design
- 🔥 Firebase backend integration
- 📸 Image upload support
- 🌍 Environment-friendly initiative
